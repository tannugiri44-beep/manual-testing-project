# DummyJSON API Testing – Postman Collection

A hands-on API Testing project built using Postman, targeting the public DummyJSON REST API.

This project demonstrates API testing fundamentals including CRUD operations, search, filtering, authentication, response validation, and automated test assertions.

## 🎯 What This Project Demonstrates

- API testing using Postman
- Writing Postman test scripts using `pm.test`
- Status code validation
- Response JSON validation
- Data validation
- CRUD operations: GET, POST, PUT, DELETE
- Search and filter API testing
- Authentication testing
- Organizing requests into a reusable Postman Collection
- Running multiple API requests using Collection Runner

## ⚙️ Tech / Tools Used

- Postman
- DummyJSON API
- JavaScript
- GitHub

## 🚀 How to Use This Collection

1. Open Postman.
2. Select Import.
3. Import the `DummyJSON_API_Testing.postman_collection.json` file.
4. Run individual requests or use Collection Runner.
5. Check the test results in Postman.

## 📌 Notes

DummyJSON is a public mock API used for API testing and learning.

POST, PUT and DELETE operations simulate changes and do not permanently modify the server data.
