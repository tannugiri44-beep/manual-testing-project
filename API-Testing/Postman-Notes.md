# API Testing Notes

## What is API Testing?
API Testing is used to verify that an API works correctly and returns the expected response.

## HTTP Methods

- POST
- PUT
- DELETE

## Status Codes
- 200 OK
- 201 Created
- 400 Bad Request
- 401 Unauthorized
- 404 Not Found
- 500 Internal Server Error
